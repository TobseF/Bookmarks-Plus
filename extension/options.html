Bookmarks+ – Extension

Language

Connection to the app

Checking …

The app only listens on 127.0.0.1. Paired browsers can also be disconnected in the app under ⚙ → Browser extension.

Import this browser's bookmarks

Copies all bookmarks of this browser once into a new folder “Import …” in Bookmarks Plus. Addresses that already exist are added there as links instead of duplicates. The browser bookmarks stay unchanged.

Keyboard shortcuts

Alt+Shift+B opens the popup, Alt+Shift+S saves the current page immediately. Change them under chrome://extensions/shortcuts (Vivaldi: Settings → Keyboard).
